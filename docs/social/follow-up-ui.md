# 后续界面需求

本文件保留用户参考规格。2026-10-04 已完成头像、封面与成员时长展示，当前实现与验收见 [本次交付](./release-2026-10-04.md)。安卓总结私信卡仍待核验载荷。

- 安卓聊天中的红色“一起听了 N 分钟”总结卡片：先确认私信类型和受控字段，支持时显示双方头像、共同收听时长及详情入口；未确认类型保留占位，不执行载荷 HTML 或未知 URL。Windows 旧客户端无法显示不代表协议没有内容。
- 原生全屏播放器复用现有专辑封面容器。房间生效时，双方头像在封面上方显示，封面平滑下移，为头像留出空间。退出房间按逆向动画恢复位置。
- 头像和封面使用同一布局容器与坐标参照；动画完成后保持固定相对间距，随窗口大小、封面大小、布局模式一起移动，禁止分别使用窗口绝对坐标。
- 状态区分等待加入、已加入、断线恢复和房间结束。等待时也显示已知头像；陌生或缺失头像沿用原头像占位。
- 采用项目已有动画、主题与小尺寸图片。隐藏窗口停止动画，遵循 reduced-motion；不新增常驻 RAF、无界 compositing layer 或整屏模糊。

验收：入房/退房各一次动画，成员变化不重复触发封面下沉；缩放/最大化/进入退出全屏不漂移；多次打开播放器不积累监听器；收听时长读取房间实际字段，不与软件总播放统计混用。
