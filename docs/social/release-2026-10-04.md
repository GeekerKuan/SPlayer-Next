## 头像与封面动画

`useTogetherPresence` 共用现有房间、账号与会话数据。等待邀请的对方头像置灰并显示三点，加入后播放栏叠合、全屏头像向中央靠拢；最多显示三个头像，其余以人数表示，保留多人房间的展示余地。

播放栏封面淡出、缩小、局部模糊退后；头像显现时容器扩大，文字和控件随容器移动，加入后随叠合收拢。展开按钮的圆形灰色遮罩覆盖头像，箭头居于组合区域中心。全屏的头像、服务端时长、封面及曲目资料使用同一布局参照，封面下移缩小，退出逆向恢复。头像不放入切歌的 keyed Transition，切歌不重建成员控件。全幅背景封面模式保留原大背景，只在资料区展示成员。

位置沿直线路径，统一复用 `cubic-bezier(0.4,0,0.2,1)`；CSS 过渡从当前插值位置重定向，无延迟完成回调或入场计时器。退出期间保留一组有界成员展示，避免先替换成空头像。隐藏页面暂停等待点动画，组件作用域回收 watcher，尊重 reduced-motion，不新增 RAF 或整屏模糊层。

播放设置“一起听歌”内的两个展示开关独立生效；旧配置缺少字段时补为开启，保留明确保存的关闭值。关闭头像只影响展示，不退出房间。时长来自已观测的 `roomInfo.effectiveDurationMs`，缺失时只显示“一起听歌”，不另建本机计时或重复统计。

安卓私信“一起听了 N 分钟”总结卡尚缺核验的消息类型与载荷；截图和退房接口 shareInfo 不能证明私信载荷相同。保留安全文字预览，不编造卡片字段、详情 URL 或 HTML。房间时长展示已实现，可选消息总结卡仍需脱敏样本。

## 用户实测清单

1. 记录旧版登录账号、主题、播放历史、插件与安装路径；退出 SPlayer（含托盘），直接安装最终 setup 到原路径。不要先卸载或清除数据。启动确认账号、设置、历史与插件仍在。
2. 消息页检查四页签、长列表滚动、详情切换、草稿、输入法和发送；观察头像是否闪烁及浅色/深色主题的视觉一致性。
3. 三点菜单打开一起听：邀请其他好友并复制链接；观察等待、加入、退出。短时间往返或切换两个展示开关，检查从当前位置过渡、缩放/最大化后对齐。
4. 默认独立模式检查双方播放/暂停/切歌/拖动；小差值确认不能再次 seek。尝试本地或其他平台歌曲，应提示限制。观察房间推荐、成员退出、断线恢复。
5. 外部房间确认“关闭旧房间并新建”只执行一次；结果未知时先核对实际房间。实测 Windows 新消息通知与点击导航。
